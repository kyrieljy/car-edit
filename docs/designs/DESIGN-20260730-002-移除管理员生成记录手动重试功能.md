# DESIGN-20260730-002：移除管理员生成记录手动重试功能

## 元信息
- **创建日期**：2026-07-30
- **状态**：已实施
- **关联需求**：在管理员界面的生成记录中，去掉"快速重试"和"一键重试"功能，同时移除所有重试相关信息的展示。

---

## 1. 背景

当前管理后台的生成记录详情页提供了管理员手动"重试任务"的能力（通过 `POST /api/admin/generations/:id/retry`），并在详情页和列表页展示了重试次数、父重试任务、重试子任务等信息。根据产品决策，管理员不应具备手动重试生成任务的操作权限，且前端不再展示任何与手动重试相关的信息和入口。

> **注意**：生成引擎内部的自动重试机制（结果质量检查失败后的自动重试）不受影响，数据库中的 `retry_count` 字段仍由引擎维护。

---

## 2. 功能描述

### 2.1 核心变更

- **移除管理员手动重试入口**：删除生成记录详情页中的"重试任务"按钮及对应操作逻辑。
- **移除后端重试 API**：删除 `POST /api/admin/generations/:id/retry` 接口。
- **移除前端重试信息展示**：
  - 详情页不再显示"重试次数"。
  - 详情页不再显示"父重试任务"。
  - 详情页不再显示"重试子任务"表格。
  - 列表页不再显示"重试次数"文本。
- **清理类型定义与 API 响应**：从管理后台相关的 TypeScript 类型和 API 响应中移除重试相关字段。

### 2.2 保留内容

以下与"重试"相关但属于其他业务域的内容**不受影响**：
- 提示词管理菜单中的"失败重试 Prompt"模板类型（属于提示词配置域）。
- 生成引擎 SOP 说明中的"自动强化缺失元素并重试一次"文案（描述引擎内部机制）。
- 数据库 `generation_jobs` 表的 `retry_count` 字段（仍由引擎自动维护）。

---

## 3. 技术实现思路

### 3.1 前端实现

1. **`components/admin/generation-detail.tsx`**
   - 移除 `RefreshCw` 图标导入（确认无其他引用后移除）。
   - 移除 `retrying` 状态、`handleRetry` 回调函数、相关 `AbortController` 引用。
   - 移除 `"重试任务"` 按钮的 JSX 区域（`analytics-detail-actions`）。
   - 移除基本信息卡片中的 `"重试次数"` 和 `"父重试任务"` 展示行。
   - 移除 `"重试子任务"` 表格区域及其 `RetryChildrenTable` 子组件定义。

2. **`components/admin-console.tsx`**
   - 在失败样本/生成记录列表的元信息区域中，移除 `<span>重试 {row.retryCount}</span>`。

### 3.2 后端实现

1. **`app/api/admin/generations/[id]/retry/route.ts`**
   - 删除整个路由文件。

2. **`lib/server/db.ts`**
   - 在 `getGenerationDetail` 函数中：
     - 移除返回类型中的 `retryCount`、`retryParentId`、`retryChildren` 字段。
     - 移除查询 `retryChildren` 的 SQL 逻辑及后续映射代码。
     - 移除返回对象中的 `retryCount: ...`、`retryParentId: ...`、`retryChildren: ...` 属性。

### 3.3 类型定义

1. **`lib/types.ts`**
   - `GenerationRecordItem` 类型：移除 `retryCount` 字段。
   - `GenerationDetailResponse` 类型：移除 `retryCount`、`retryParentId`、`retryChildren` 字段。

## 7. 实施步骤

按以下顺序执行：

1. **删除后端 API 路由**：删除 `app/api/admin/generations/[id]/retry/route.ts`。
2. **修改数据库层**：在 `lib/server/db.ts` 的 `getGenerationDetail` 中移除 `retryCount`、`retryParentId`、`retryChildren` 的返回类型声明、SQL 查询逻辑及返回属性。
3. **更新类型定义**：在 `lib/types.ts` 中从 `GenerationRecordItem` 移除 `retryCount`，从 `GenerationDetailResponse` 移除 `retryCount`、`retryParentId`、`retryChildren`。
4. **修改详情页组件**：在 `components/admin/generation-detail.tsx` 中移除重试按钮、重试状态/处理函数、重试次数/父重试任务展示行、重试子任务表格组件定义及使用。
5. **修改列表页组件**：在 `components/admin-console.tsx` 中移除 `<span>重试 {row.retryCount}</span>`。
6. **类型检查**：运行 `npx tsc --noEmit` 验证无 TypeScript 编译错误。
7. **更新文档**：同步更新 `docs/API_REFERENCE.md` 和 `docs/CHANGELOG.md`。
