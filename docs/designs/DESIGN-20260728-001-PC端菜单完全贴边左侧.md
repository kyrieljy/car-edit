# DESIGN-20260728-001：PC端菜单完全贴边左侧

## 元信息
- **创建日期**：2026-07-28
- **状态**：草稿
- **关联需求**：将PC端的菜单（改图、生图、特效）贴到窗口（浏览器）的最左边

---

## 1. 背景

当前 PC 端浮动垂直菜单（`.app-floating-rail`）使用 `left: 4px` 定位，与浏览器窗口左边缘保留 4px 间距，呈现为悬浮卡片效果（带圆角、阴影、半透明背景）。用户希望菜单完全贴到浏览器窗口最左边（`left: 0`），去掉 4px 间距，使菜单与窗口边缘无缝衔接。收起状态（`.app-floating-rail-collapsed`）也需同样贴边处理。

## 2. 功能描述

- 将展开状态菜单（`.app-floating-rail`）的 `left` 值从 `4px` 改为 `0`，使菜单完全贴紧浏览器窗口左边缘。
- 将收起状态菜单（`.app-floating-rail-collapsed`）的 `left` 值从 `4px` 改为 `0`，保持一致。
- 去掉左侧圆角（`border-radius` 改为仅右侧圆角），使菜单左边缘与窗口边缘齐平，视觉上融为一体。
- 去掉左侧和上方的阴影，仅保留右侧和下方的微妙阴影，避免在贴边时产生不自然的投影效果。
- Tooltip（hover 提示文字）位置保持不变（显示在菜单项右侧），不受贴边影响。
- 菜单的垂直居中位置（`top: 50% + translateY(-50%)`）、z-index、媒体查询等均保持不变。
- 不影响移动端（移动端不显示此浮动菜单）。
- 不影响亮色/暗色主题下的菜单样式表现。

## 3. 技术实现思路

本次变更仅涉及 CSS 样式调整，无需修改组件逻辑。

**核心变更**：
1. `.app-floating-rail` 的 `left` 从 `4px` 改为 `0`。
2. `.app-floating-rail-collapsed` 的 `left` 从 `4px` 改为 `0`。
3. 两个选择器的 `border-radius` 从 `12px` 改为 `0 12px 12px 0`（仅右侧保留圆角），使左侧与窗口齐平。
4. 调整 `box-shadow` 为仅右侧和下侧投影，避免在 `left: 0` 时左侧阴影被窗口裁切或产生不自然效果。
5. 验证亮色主题下菜单贴边效果是否协调（检查 `[data-theme="light"]` 下是否有覆盖样式需要同步调整）。

## 6. 风险与应对

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| 亮色主题下左侧贴边后视觉不协调（白背景与白色菜单融为一体） | 低 | 低 | 贴边后仍保留右侧阴影和圆角，确保菜单在亮色主题下有足够的视觉边界；如有需要可在亮色主题下给菜单加右侧 1px 边框 |

## 7. 实施步骤

1. 在 `app/globals.css` 中定位 `.app-floating-rail` 样式块，将 `left: 4px` 改为 `left: 0`。
2. 同一选择器中，将 `border-radius: 12px` 改为 `border-radius: 0 12px 12px 0`。
3. 调整 `.app-floating-rail` 的 `box-shadow`，去掉左侧阴影方向，保留右侧和下侧。
4. 定位 `.app-floating-rail-collapsed` 样式块，执行同样的 `left`、`border-radius`、`box-shadow` 修改。
5. 搜索 `[data-theme="light"]` 作用域内是否有对 `.app-floating-rail` 或 `.app-floating-rail-collapsed` 的覆盖样式，若有则同步调整。
6. 启动开发服务器，在 PC 端浏览器中验证展开和收起两种状态的贴边效果。
7. 切换亮色/暗色主题，确认两种主题下菜单贴边视觉效果正常。
8. 更新 `docs/CHANGELOG.md`。
