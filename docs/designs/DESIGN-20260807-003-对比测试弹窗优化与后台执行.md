# DESIGN-20260807-003：对比测试弹窗大图化、后台执行与全局提醒

## 元信息
- **创建日期**：2026-08-07
- **状态**：已实现（2026-08-07 编码完成，`tsc --noEmit` 通过）
- **关联需求**：基于 DESIGN-20260807-002（画质参数对比测试与测试配件设置）的「对比测试」能力，做三项体验增强：① 弹窗内生成的效果图放大展示、弹窗可滚动；② 点击「对比测试」后生图任务转为后台执行，关闭弹窗不中止任务，并提示用户可关闭弹窗，生成结束后在管理后台任意菜单给出完成提醒；③ 画质参数下拉中移除「不传（使用平台默认）」选项，枚举值严格按用户配置传参。
- **前置方案**：DESIGN-20260807-002（弹窗与原生对比测试逻辑）、DESIGN-20260807-001（画质参数可配置化、保留值语义）

## 1. 背景

### 1.1 现状

DESIGN-20260807-002 已在「模型 API」菜单「画质参数」分区为每个参数提供「对比测试」按钮（`components/admin-console.tsx:3388`），点击后通过 `app/api/admin/provider-configs/compare-test/route.ts` 同步并行生图，结果以弹窗展示。当前存在三处体验短板：

1. **图太小看不清**：效果图使用 `.image-param-compare-thumb`（`app/globals.css:25781`，`width:104px;height:68px` object-fit:cover），缩略图极小，管理员难以判断画质差异，无法据此调参。
2. **前台阻塞、关闭即丢失**：`ImageParamCompareModal`（`admin-console.tsx:2864`）在 `useEffect` 内 `await` 整个 `POST`（服务端 `Promise.allSettled` 全部生图完成后才返回），弹窗在生图期间为「加载中」且不可脱离；用户一旦关闭弹窗，组件卸载、轮询/结果状态随销毁，已发起的生图虽在服务器端跑完但结果无后续提醒，管理员必须守在弹窗前等待。
3. **下拉含「不传」选项**：每个画质参数下拉除用户配置的枚举值外，还额外注入一项「不传（使用平台默认）」（`IMAGE_PARAM_VALUE_NONE`，`admin-console.tsx:3379`），与「枚举值严格按用户设置传参」的诉求相悖。

### 1.2 需求价值

- **大图 + 滚动**：让管理员在弹窗内直接、清晰地对比各枚举值的真实出图质量，支撑有理据的调参。
- **后台执行 + 全局提醒**：生图耗时（枚举值个数 × 单次生图，通常 4-7 次真实调用）较长，应允许管理员关闭弹窗去处理其它后台事务；任务在后台独立推进，完成后无论管理员当前停留在哪个菜单（只要仍在管理后台）都主动提醒，不再要求「守弹窗」。
- **纯枚举传参**：去掉「不传（使用平台默认）」，画质参数取值严格收敛到用户显式配置的枚举值集合。

## 2. 功能描述

### 2.1 核心用户故事

> 作为管理员，我在「模型 API」菜单某画质参数旁点击「对比测试」后，弹窗立刻提示「任务已在后台执行，您可以随时关闭本弹窗，生成结束后会在任意菜单提醒您」。弹窗内每个枚举值的效果图以足够大的尺寸展示，弹窗本身可纵向滚动逐行查看。我直接关掉弹窗去配置其它 Provider；几分钟后，管理后台右上角弹出 toast：「对比测试已完成（参数 quality，共 4 个枚举值）」，我点开「对比测试」即可看到全部结果。另外，画质参数下拉里不再出现「不传（使用平台默认）」选项，我只能从自己配置的枚举值中选定。

### 2.2 功能点清单

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 效果图放大展示 | 弹窗内「效果图」列由 104×68 缩略图改为大图（`width:min(420px,100%);height:auto;max-height:520px;object-fit:contain`），清晰呈现画质差异 |
| F2 | 弹窗可滚动 | 弹窗保持 `.provider-test-modal{max-height:80vh;overflow:hidden}`，内容区 `.provider-test-table-wrap{overflow:auto}` 已支持纵向滚动；放大图片后逐行滚动查看 |
| F3 | 后台执行任务 | 点击「对比测试」后，生图任务与弹窗生命周期解耦：任务提升到 `AdminConsole` 顶层状态，弹窗关闭不影响任务推进与服务端生图 |
| F4 | 关闭提示文案 | 弹窗打开即展示提示：「任务已在后台执行，可随时关闭本弹窗，生成结束后会在任意菜单提醒您」 |
| F5 | 全局完成提醒 | 任务（轮询）检测全部枚举值达终态（succeeded/failed）后，调用顶层已有 `notify()`（`setToast`，`admin-console.tsx:359`，渲染于 `:649`），在管理后台任意菜单均弹出完成提示 |
| F6 | 弹窗仅做展示 | `ImageParamCompareModal` 改为只读展示顶层 `compareJobs` 的轮询结果，不再自行 `await` POST 阻塞 UI |
| F7 | 移除「不传」选项 | `ProviderImageParamsEditor`（`admin-console.tsx:3369` 下拉）删除 `<option value={IMAGE_PARAM_VALUE_NONE}>不传（使用平台默认）</option>`，下拉仅含 `param.options`（含 `__auto__`「跟随原图」） |
| F8 | 严格按枚举传参 | 保留 `IMAGE_PARAM_VALUE_NONE` 常量与 `route.ts:81` 的 `param.options.filter((v) => v !== "")` 空值过滤（防御性），但 UI 不再暴露该选项，取值严格收敛到用户枚举 |

### 2.3 需求澄清结论（已与需求方确认）

| 议题 | 结论 |
|------|------|
| 大图尺寸 | 效果图展示为 `min(420px,100%)` 宽、自适应高、最大 520px，弹窗纵向可滚动 |
| 后台执行方式 | 生图任务提升到 `AdminConsole` 顶层，弹窗关闭不中止任务；采用「POST 触发 + GET 轮询至终态」模式，轮询独立于弹窗 |
| 完成提醒范围 | 只要管理员仍在管理后台（任一菜单），生成结束后弹顶层 toast 提醒；离开后台不保证 |
| 「跟随原图」(__auto__) 去留 | **保留**：仅移除「不传（使用平台默认）」，`__auto__` 作为保留枚举值继续可用 |
| 是否改 route 行为 | POST 可保持同步返回（服务端 `Promise.allSettled` 本就不受前端关闭影响），也可改为「先 202 接单 + 轮询」；本次默认采用轮询模式以解耦前端 |

### 2.4 非功能性要求

- **不阻塞后台其它操作**：后台执行期间，管理员可自由切换菜单、编辑配置、关闭弹窗。
- **结果一致性**：后台任务与弹窗共用同一份轮询结果（顶层 `compareJobs`），弹窗重新打开时展示最新进度/结果。
- **兼容性**：用户端生图链路、画质参数注入器、一键测试（`test-all`）等既有能力不变；仅调整对比测试弹窗展示、任务生命周期与下拉选项。

## 3. 影响文件与改动点

### 3.1 `components/admin-console.tsx`
- `AdminConsole` 主组件（约 line 323）新增：
  - `compareJobs` 状态：`Record<string, { providerId; paramKey; rows: ImageParamTestResult[]; status: 'running'|'done'; }>`（以 `providerId::paramKey` 为 key）。
  - `startCompareTest(providerId, paramKey)`：发起 `POST /api/admin/provider-configs/compare-test` 触发生图；随即启动 `setInterval` 每 1.5s `GET` 同一接口，直到所有 `rows` 为终态；终态后 `notify('success', '对比测试已完成（参数 X，共 N 个枚举值）')` 并停止轮询。
  - `onCompareTest`（现 `ProviderImageParamsEditor` 的 prop）改为调用 `startCompareTest` 而非直接打开弹窗；打开弹窗仅作展示。
- `ImageParamCompareModal`（line 2864）：
  - 移除本地 `useEffect` 内 `await POST` 的阻塞逻辑；改为从 `compareJobs[key]` 读取行数据（props 传入）。
  - 新增提示文案区块（F4）。
  - `regenerate` 仍走单值 `POST`，并同步写入 `compareJobs[key].rows`。
- `ProviderImageParamsEditor`（line 3369-3380）：删除 line 3379 的「不传（使用平台默认）」`<option>`（F7）。

### 3.2 `app/globals.css`
- `.image-param-compare-thumb`（line 25781）：尺寸由 `104×68` 改为大图样式（F1）。
- `.image-param-compare-modal`（line 25757）：宽度 `760px` → `min(960px,94vw)`，给大图留出空间。

### 3.3 `app/api/admin/provider-configs/compare-test/route.ts`
- （可选增强，默认采用）POST 触发后保持返回 `results` 现状即可；若改为异步接单模式，则 POST 先返回 `{ jobId }` 202，由前端轮询 GET。当前同步返回对「关闭弹窗不中止」无碍（服务端跑完），故**最小改动可不改此文件**，仅在 F3/F5 依赖前端轮询。
