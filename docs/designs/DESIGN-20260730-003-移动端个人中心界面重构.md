## 1. 背景

当前移动端个人中心（`MobileProfilePage` 组件）采用居中大头像 Hero 区 + 三列统计栏 + 圆角卡片式列表行的布局风格。该设计存在以下问题：

- Hero 区占用大量纵向空间，首屏信息密度低
- 统计栏与列表行视觉风格割裂，整体层次不够清晰
- 圆角卡片式列表行（每行 78px 高度 + 圆形图标 + 独立阴影）在移动端显得臃肿

参考项目 grab-ui 采用了更紧凑、更现代的个人中心布局：横向个人资料卡片 + 简洁的 border-bottom 分隔列表行。本次重构将借鉴该布局结构，同时保持项目现有的暗黑奢华视觉风格（ADR-0004），不改变颜色主题。

## 2. 功能描述

### 核心变更

将移动端个人中心的 overview 主页面布局从「居中 Hero + 统计栏 + 卡片列表」重构为「横向资料卡片 + 操作按钮 + 简洁列表」，布局结构对齐 grab-ui，颜色保持黑色主色。

### 具体功能点

1. **个人资料卡片**（替代原 Hero 区 + 统计栏）
   - 横向布局：左侧圆形头像（50px）+ 昵称，右侧"编辑资料"按钮
   - 未登录时：头像占位 + "点击登录"按钮
   - 卡片下方两个横向操作按钮（替代原统计栏）：
     - 左按钮：「订阅套餐」→ 触发 `openSubscribe`
     - 右按钮：「我的订单」→ 触发 `openOrders`
   - 按钮样式参考 grab-ui 的 `Join GrabUnlimited` / `Track progress`：带边框的圆角胶囊按钮

2. **列表区**（替代原卡片式列表）
   - 移除所有行的圆形图标
   - 改用 border-bottom 分隔的简洁行样式
   - 每行结构：左侧标题文字 + 右侧可选值/徽标 + ChevronRight 箭头
   - 菜单项顺序（不分组）：
     1. 消息通知（右侧显示未读数红点徽标，替代原顶部消息按钮）
     2. 编辑资料
     3. 换绑手机号（右侧显示当前手机号）
     4. 修改密码
     5. 订阅与套餐（右侧显示当前套餐名）
     6. 我的订单
     7. 退出账号（危险样式）
   - 未登录时：仅显示「登录账号」行

3. **顶部栏调整**
   - 保留返回按钮 + "个人中心"标题
   - 移除右上角消息通知按钮（消息入口移入列表）

4. **颜色方案**（保持黑色主色）
   - 页面背景：保持现有暗黑渐变背景（`#050607` + radial-gradient）
   - 资料卡片：使用 `--m-raised` 深色背景 + 圆角 + 轻微阴影
   - 操作按钮：透明背景 + `--m-border` 边框 + `--m-text` 文字
   - 列表行：透明背景，border-bottom 使用半透明白色
   - 标题文字：`--m-text`
   - 副文字/值：`--m-muted`
   - 危险操作（退出）：红色文字
   - 未读徽标：保持红色 `#ff3b4f`

### 非功能性需求

- 亮色主题（`[data-mobile-theme="light"]`）需同步适配新布局
- 页面过渡动画（framer-motion）保持不变
- 子页面（编辑资料/密码/手机/消息/订单）渲染逻辑保持不变，仅 overview 布局变更

## 3. 技术实现思路

### 整体策略

仅修改 `MobileProfilePage` 组件中 `section === "overview"` 时的渲染逻辑（即 overview 主页面的 JSX 结构），以及对应的 CSS 样式。不涉及状态管理、数据获取、子页面渲染等逻辑的变更。

### JSX 结构变更

将 overview 页面的 JSX 从当前的：
```
header（topbar + 消息按钮）
hero（居中头像 + 昵称 + 描述）
stats（三列统计栏）
list（卡片式行：图标 + 标题/描述 + 箭头）
```

重构为：
```
header（topbar，仅返回按钮 + 标题，移除消息按钮）
profile-card（横向：头像 + 昵称 + 编辑按钮）
action-buttons（两个胶囊按钮：订阅套餐 / 我的订单）
list（简洁行：标题 + 可选值 + 箭头，border-bottom 分隔）
```

### CSS 变更策略

1. **新增样式类**：
   - `.mobile-profile-card`：横向资料卡片容器
   - `.mobile-profile-card-header`：头像 + 昵称 + 按钮的横向布局
   - `.mobile-profile-card-actions`：两个操作按钮的横向布局
   - `.mobile-profile-simple-list`：简洁列表容器
   - `.mobile-profile-simple-row`：简洁列表行（无图标、border-bottom 分隔）

2. **修改现有样式**：
   - `.mobile-profile-topbar`：移除消息按钮相关的 `data-has-messages` 隐藏逻辑
   - `.mobile-profile-message-trigger`：保留样式但不再在 overview 顶部渲染（子页面 header 不受影响）

3. **保留不动的样式**：
   - `.mobile-profile-page`（页面容器、背景）
   - `.mobile-profile-edit-screen`（子页面容器）
   - `.mobile-profile-editor`（编辑表单）
   - `.mobile-profile-avatar`（头像样式，但尺寸从 116px 缩小到 50px 用于卡片内）
   - 所有子页面相关样式（消息列表、订单列表等）

### 交互逻辑

- 消息通知行点击 → 调用 `openMessages()`（与原顶部消息按钮逻辑一致）
- 编辑资料按钮/行点击 → 调用 `openProfileSection("profile")`
- 订阅套餐按钮/行点击 → 调用 `openSubscribe()`
- 我的订单按钮/行点击 → 调用 `openOrders()`
- 退出账号行点击 → `onClose()` + `logout()`
- 所有交互函数均已存在，无需新增
