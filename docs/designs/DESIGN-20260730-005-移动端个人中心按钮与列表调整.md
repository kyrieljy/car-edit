# DESIGN-20260730-005：移动端个人中心按钮与列表调整

## 元信息
- **创建日期**：2026-07-30
- **状态**：已实施
- **关联需求**：调整移动端个人中心 overview 主页面的按钮显示内容与列表项，使套餐信息和剩余额度在首屏直接可见，减少冗余入口

---

## 1. 背景

当前移动端个人中心（`MobileProfilePage` 组件，由 DESIGN-20260730-003 重构产生）的 overview 主页面布局如下：

- **个人资料卡片**：头像 + 昵称 + "编辑资料"按钮，卡片下方两个操作按钮：
  - 左按钮：「订阅套餐」→ 触发 `openSubscribe`
  - 右按钮：「我的订单」→ 触发 `openOrders`
- **简洁列表**：消息通知、编辑资料、换绑手机号、修改密码、订阅与套餐、我的订单、退出账号

用户反馈：首屏两个操作按钮的文案为静态文字"订阅套餐"和"我的订单"，无法直接反映当前账号状态；下方列表中"编辑资料"和"订阅与套餐"两个入口与卡片区域的按钮功能重复，造成冗余。需要将按钮改为直接展示用户当前套餐名称和剩余额度，并移除列表中的重复入口。

## 2. 功能描述

### 核心变更

对 `MobileProfilePage` 组件 overview 主页面进行三处调整：卡片操作按钮文案动态化、列表项精简。

### 具体功能点

1. **左操作按钮：显示套餐名称**
   - 原文案：「订阅套餐」/「Subscribe」
   - 新文案：直接显示当前用户的套餐名称（如 Free、Pro、Max）
   - 数据来源：复用已有的 `planName` 变量（`billing?.plan.label || authUser?.plan || "游客"/"Guest"`）
   - 点击行为：保持不变，仍触发 `openSubscribe`（打开订阅弹窗，允许用户升级/切换套餐）
   - 图标：保留 `Sparkles` 图标

2. **右操作按钮：显示剩余额度**
   - 原文案：「我的订单」/「Orders」
   - 新文案：显示生成剩余次数和对话剩余次数，格式为：
     - 中文：`生成 {configBalance} · 对话 {chatBalance}`
     - 英文：`Gen {configBalance} · Chat {chatBalance}`
   - 数据来源：
     - `configBalance`：`billing.configRemaining`（number | "unlimited"），通过 `formatMobileProfileBalance` 格式化，unlimited 显示"不限"/"Unlimited"
     - `chatBalance`：`billing.chatRemainingToday`（number | "unlimited"），同上格式化
     - 当 `billing` 为 null（未加载/未登录）时，显示 `--`
   - 点击行为：由 `openOrders` 改为 `openSubscribe`（打开订阅弹窗，用户额度不足时可升级）
   - 图标：由 `Receipt` 改为 `Zap`（闪电图标，更贴合"额度/能量"语义）
   - 我的订单入口保留在下方列表中，不受影响

3. **列表项精简**
   - 移除「编辑资料」行（原位于列表第 2 项，触发 `openProfileSection("profile")`）
     - 编辑资料功能仍可通过卡片头部的"编辑资料"按钮访问，不受影响
   - 移除「订阅与套餐」行（原位于列表第 5 项，触发 `openSubscribe`）
     - 订阅功能仍可通过卡片左操作按钮（现显示套餐名称）访问，不受影响
   - 精简后列表顺序：消息通知 → 换绑手机号 → 修改密码 → 我的订单 → 退出账号

### 非功能需求

- 套餐名称和额度数值需实时反映 `billing` 状态，无需额外请求
- 暗色/亮色主题兼容：按钮样式复用现有 `.mobile-profile-card-actions button` CSS 规则，无需新增主题适配
- 按钮文案变长后需确保不溢出：右按钮文案可能较长（如"生成 不限 · 对话 不限"），需在 CSS 层面做字号微调或允许等比缩小

## 3. 技术实现思路

### 整体策略

仅修改 `MobileProfilePage` 组件的 JSX 渲染逻辑和少量 CSS，不涉及数据层、API、路由变更。`planName`、`billing`、`formatMobileProfileBalance` 等变量和函数已在组件作用域内可用，直接复用。

### 关键逻辑

1. **套餐名称按钮**
   - 将左按钮的文案节点从 `{isZh ? "订阅套餐" : "Subscribe"}` 替换为 `{planName}`
   - `planName` 已在组件第 2749 行定义，无需新增变量

2. **剩余额度按钮**
   - 需新增两个局部变量计算格式化后的额度值：
     - `configBalance`：`billing ? formatMobileProfileBalance(billing.configRemaining, isZh ? "不限" : "Unlimited") : "--"`
     - `chatBalance`：`billing ? formatMobileProfileBalance(billing.chatRemainingToday, isZh ? "不限" : "Unlimited") : "--"`
   - 将右按钮的文案节点替换为 ``{isZh ? `生成 ${configBalance} · 对话 ${chatBalance}` : `Gen ${configBalance} · Chat ${chatBalance}`}``
   - 将右按钮的 `onClick` 从 `openOrders` 改为 `openSubscribe`
   - 将右按钮的图标从 `Receipt` 改为 `Zap`（需确认 `Zap` 已从 lucide-react 导入，若未导入则补充 import）

3. **列表项移除**
   - 删除简单列表中「编辑资料」按钮的整个 `<button>` 块（原第 3272-3275 行）
   - 删除简单列表中「订阅与套餐」按钮的整个 `<button>` 块（原第 3287-3293 行）

### CSS 调整

- 右按钮文案变长，需在 `.mobile-profile-card-actions button` 规则中补充：
  - `font-size` 可从 13px 降至 12px，或保持 13px 并添加 `white-space: nowrap` + `overflow: hidden` + `text-overflow: ellipsis`
  - 推荐方案：保持 13px，添加 `white-space: nowrap`，配合 `min-width: 0` 防止 flex 溢出

### 与现有模块的交互

- `openSubscribe`：已有函数（第 2761 行），设置 `setSubscribeOpen(true)`，无需修改
- `formatMobileProfileBalance`：已有函数（第 3473 行），处理 `"unlimited"` → 文字转换，无需修改
- `planName`：已有变量（第 2749 行），无需修改
- `LegacyMobileProfilePage`：未被任何组件引用，不修改
