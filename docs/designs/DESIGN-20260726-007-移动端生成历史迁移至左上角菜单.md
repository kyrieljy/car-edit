# DESIGN-20260726-007：移动端生成历史迁移至左上角菜单

## 元信息
- **创建日期**：2026-07-26
- **状态**：待审核
- **关联需求**：去掉移动端个人信息中的"生成历史"按钮及子页面，将生成历史内容放入左上角菜单；左上角菜单在配置模式下展示4个子菜单后再展示生成历史，在对话模式下展示4个子菜单后再展示会话历史。

---

## 1. 背景

当前移动端的"生成历史"入口位于个人信息页面（`MobileProfilePage`）的 `mobile-profile-list` 中，作为 `section === "history"` 子页面存在（复用 `MobileHistorySheet` 渲染历史记录列表）。这一入口层级较深，用户需要先打开个人中心才能查看生成历史，不够直观。

与此同时，左上角菜单（`MobileMenuDrawer`）已经承担了"功能导航 + 对话历史"的聚合角色：四子菜单下方在对话模式下会展示会话历史（`MobileMenuChatHistory`），但配置模式下不展示任何历史内容，导致两种模式下的菜单体验不对称。

为统一左上角菜单作为"历史入口"的心智模型，需将生成历史从个人信息迁移至左上角菜单的配置模式分支，使两种模式在菜单中都能"先看四子菜单、再看对应历史"。

## 2. 功能描述

### 2.1 去掉个人信息中的"生成历史"入口

- 移除 `MobileProfilePage` 的 `mobile-profile-list` 中"生成历史"按钮（第 3175-3182 行）。
- 移除 `MobileProfileSection` 类型中的 `"history"` 选项。
- 移除 `renderEditor` 中 `section === "history"` 的渲染分支（第 3002-3016 行）。
- 清理 `profileSectionTitle` 中对 `history` 的判断（本就无 history 分支，确认无需清理）。
- `MobileHistorySheet` 组件本身保留（菜单中复用），不删除。

### 2.2 左上角菜单配置模式下展示生成历史

- `MobileMenuDrawer` 当前仅在 `appMode === "chat"` 时展示 `MobileMenuChatHistory`，现扩展为：
  - `appMode === "config"`：在四子菜单下方展示"生成历史"区块，复用 `MobileHistorySheet` 的数据与交互（选中、删除）。
  - `appMode === "chat"`：保持现有 `MobileMenuChatHistory` 行为不变。
- 区块标题与"对话历史"区块在视觉风格上保持一致（标题 + 可滚动列表）。

### 2.3 用户交互行为

- 在配置模式下点击菜单中某条生成历史：关闭菜单抽屉 → 加载该历史记录到配置界面（与原个人信息中点击历史的行为一致，复用 `selectHistoryJob`）。
- 删除单条历史：复用 `deleteHistoryJob`，删除后列表实时更新。
- 选中态高亮：复用 `job?.id` 判断当前选中项，与 `MobileHistorySheet` 的 `selected` 样式一致。
- 空状态：当 `history` 为空时，展示"暂无生成历史"提示文案（复用 `t.historyEmpty` 或等价文案），区块标题仍展示，与对话历史的空状态处理一致。

### 2.4 非功能性要求

- 主题适配：新增的"生成历史"区块需同时适配暗色与亮色主题，复用 `MobileHistorySheet` 与 `mobile-menu-chat-history` 已有的样式变量，不引入新的硬编码颜色。
- 动画：菜单抽屉的开合动画不变；历史列表区块随抽屉一同出现，无需独立动画。

## 3. 技术实现思路

### 3.1 数据流

配置模式的生成历史数据（`history`、`job`、`selectHistoryJob`、`deleteHistoryJob`、`formatHistoryTitle`、`t`）已通过 `MobileStudioAppProps` 从顶层 `MobileStudioApp` 下传，`MobileProfilePage` 当前就是消费这些 props。

迁移策略：将同样的 props 透传给 `MobileMenuDrawer`，使其在配置模式下能够渲染 `MobileHistorySheet`。无需新增状态提升或 hook 提取，数据通路已存在。

对话模式的 `chatHistoryApi` 通路保持不变。

### 3.2 MobileMenuDrawer 扩展

**Props 扩展**：
- 新增 `history`、`job`、`selectHistoryJob`、`deleteHistoryJob`、`formatHistoryTitle`、`t`（均为 `MobileStudioAppProps` 的子集），用于配置模式下渲染 `MobileHistorySheet`。
- `appMode`、`chatHistoryApi`、`language`、`onSelect`、`onClose`、`open` 保持不变。

**渲染逻辑**：
- 四子菜单（`mobile-menu-grid`）渲染保持不变。
- 四子菜单下方，根据 `appMode` 条件渲染：
  - `appMode === "chat"` 且 `chatHistoryApi` 存在：渲染 `MobileMenuChatHistory`（现有逻辑）。
  - `appMode === "config"`：渲染新增的 `MobileMenuGenerationHistory` 组件。

**新增组件 `MobileMenuGenerationHistory`**：
- 结构对齐 `MobileMenuChatHistory`：外层容器 `mobile-menu-gen-history`，内含标题区（"生成历史"文案）+ 可滚动列表区。
- 列表复用 `MobileHistorySheet`，但传入 `setSheet={() => {}}` 与 `onClose={onClose}`，使点击历史时关闭菜单抽屉。
- 空状态：当 `history.length === 0` 时，展示 `t.historyEmpty`（或等价文案）。

### 3.3 MobileMenuDrawer 调用处修改

`MobileStudioApp` 第 739-749 行的 `MobileMenuDrawer` 调用处，新增 `history`、`job`、`selectHistoryJob`、`deleteHistoryJob`、`formatHistoryTitle`、`t` 的透传（从 `props` 中取）。

### 3.4 个人信息清理

- `MobileProfileSection` 类型移除 `"history"`：`type MobileProfileSection = "overview" | "profile" | "password" | "phone" | "messages"`。
- `renderEditor` 移除 `section === "history"` 分支。
- `mobile-profile-list` 中移除"生成历史"按钮 JSX。
- `openProfileSection` 调用处不再有 `"history"` 入参，无需额外清理。
- `LegacyMobileProfilePage`（第 3239 行）本就没有"生成历史"按钮，无需改动。

### 3.5 样式

- 新增 `.mobile-menu-gen-history` 容器样式，对齐 `.mobile-menu-chat-history` 的布局（标题区 + 滚动列表区 + 内边距）。
- 复用现有的 `.mobile-history-card`、`.mobile-history-card.selected`、`.mobile-history-delete`、`.mobile-history-empty` 样式，不重复定义。
- 亮色模式：`MobileMenuChatHistory` 已有的 `[data-theme="light"]` 覆盖规则应同样适用于生成历史区块（因复用 `MobileHistorySheet` 的 class）。编码时确认 `.mobile-menu-gen-history` 容器本身在亮色下的背景与文字色，必要时新增 `[data-theme="light"] .mobile-menu-gen-history` 覆盖。

## 7. 实施步骤

1. **清理个人信息历史入口**：在 `mobile-studio-app.tsx` 中移除 `MobileProfileSection` 的 `"history"` 选项；移除 `renderEditor` 中 `section === "history"` 分支；移除 `mobile-profile-list` 中"生成历史"按钮 JSX。
2. **扩展 MobileMenuDrawer Props**：在 `MobileMenuDrawer` 的 props 类型中新增 `history`、`job`、`selectHistoryJob`、`deleteHistoryJob`、`formatHistoryTitle`、`t` 字段。
3. **新增 MobileMenuGenerationHistory 组件**：实现配置模式下的生成历史区块，复用 `MobileHistorySheet`，结构对齐 `MobileMenuChatHistory`（标题 + 滚动列表 + 空状态）。
4. **MobileMenuDrawer 渲染分支**：在四子菜单下方，`appMode === "config"` 时渲染 `MobileMenuGenerationHistory`，`appMode === "chat"` 时保持渲染 `MobileMenuChatHistory`。
5. **MobileMenuDrawer 调用处透传 props**：在 `MobileStudioApp` 第 739-749 行的 `MobileMenuDrawer` 调用处，从 `props` 中透传 `history`、`job`、`selectHistoryJob`、`deleteHistoryJob`、`formatHistoryTitle`、`t`。
6. **CSS 新增样式**：在 `globals.css` 中新增 `.mobile-menu-gen-history` 容器样式，对齐 `.mobile-menu-chat-history`；确认滚动列表区样式复用 `chat-history-scroll` 或等价规则。
7. **亮色适配验证**：在亮色模式下检查 `.mobile-menu-gen-history` 区块的背景与文字色，必要时新增 `[data-theme="light"]` 覆盖。
8. **回归验证**：配置模式下打开菜单 → 查看生成历史 → 点击某条历史 → 菜单关闭且配置界面加载该历史；删除历史 → 列表更新；空历史 → 展示空状态文案；对话模式下菜单行为无回归；个人信息页面不再有"生成历史"按钮且其他子页面正常。
