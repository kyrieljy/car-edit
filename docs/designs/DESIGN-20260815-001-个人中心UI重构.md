# DESIGN-20260815-001：个人中心 UI 重构

## 元信息
- **创建日期**：2026-08-15
- **状态**：草稿（待审核）
- **关联需求**：基于《UI优化方案.md》（设计提案 V1，项目根目录）落地"个人中心"重设计——将现有功能型弹层重构为"改装车间指挥中心"风格的个人中心，新增「概览 / 我的车库 / 用量」三大区块，强化账户/会员/订单，并补齐桌面端 light 主题、可访问性与动效编排。
- **关联设计文档**：`UI优化方案.md`（根目录，设计提案）；本方案为落地执行计划，不重复设计细节，仅描述技术实现与变更点。
- **前置约束**：禁止修改 `car-mod-studio.tsx` 对 `PcAccountPanel` 的调用契约；项目无 Tailwind，继续手写 CSS 变量；不引入新 UI 组件库。

## 0. 需求澄清与假设（回应 UI优化方案.md §11）

经代码与架构实地核查，原提案的 5 个开放问题中，3 个已可明确结论，2 个需确认：

| 原问题 | 核查结论 / 决策 |
|--------|----------------|
| ① 用户生成记录接口 | **已存在，复用即可**。路由层已有 `GET /api/garage`（`app/api/garage/route.ts`），调用 `requireUser()` + `listUserGenerations(user.id)`，返回当前用户本人的、状态 `succeeded`、有结果图的 `config` 模式生成记录（上限 80）。**无需新建 `GET /api/generations/mine`**（原提案 §9.4 假设作废，避免冗余端点）。`GenerationJob` 字段（`resultImageUrl` / `displayVehicleModel` / `mode` / `createdAt`）足以渲染网格与"最近 3 件"。 |
| ② 自助开通策略 | **待产品确认（唯一阻断性决策）**。会员区块 CTA 形态取决于 `USER_SUBSCRIPTION_CHECKOUT_ENABLED` 的真实取值。方案按"双态兼容"实现：开关开启 → 显示定价卡 + 支付浮层；关闭 → 显示"联系管理员"信息条（沿用现有 `subscriptionManaged` 文案）。无论哪种，UI 都已覆盖，不改组件结构。 |
| ③ 我的车库是否支持再编辑 | **本期定为只读画廊 + 详情浮层**；"重新编辑/再载入"跳转工作室为可选 Phase-2（需 `car-mod-studio` 支持按 `generationId` 载入历史配置，属独立增量，不在本方案范围）。 |
| ④ 多端一致性 | **本期范围限定桌面端 `pc-account-panel`**。移动端现由 `components/mobile/mobile-studio-app.tsx` 内独立"用户中心历史子页面"承载，本方案不改动移动端；一致化（移动端复用同一组件 + 底部抽屉）列为后续跟进，避免一次改动面过大。 |
| ⑤ 用量火花线数据源 | **需新增 1 个聚合端点**。底层数据已落库（`usage_ledger`、`entitlement_usage` 含每日 `used`），但 `getBillingStatus` 仅返回当前快照、无历史序列。新增 `GET /api/usage?days=7` 按 `user_id` + `date_key` 聚合近 N 日每日消耗，支撑火花线。 |

> 其余设计细节（美学方向、Token、线框、动效、a11y）以《UI优化方案.md》为准，本方案不再复述，仅在 §3/§4 描述落地方式。

## 1. 背景

现存"个人中心"实现于 `components/pc-account-panel.tsx`（1037 行），是一个功能正确但体验单薄的三栏弹层（账户 / 订阅 / 订单）。其痛点已记录在《UI优化方案.md》§2：与产品核心价值（AI 生成改装预览）割裂、无作品入口、无概览首屏、额度展示扁平、桌面端无 light 主题、动效与可访问性弱。

《UI优化方案.md》已给出"改装车间指挥中心 / Garage Command Center"的设计方向（暗色 HUD、霓虹青绿 `--teal:#67ffca` 强调、琥珀告警、等宽数据字体）。本方案据此产出可执行的开发计划，目标是把设计提案转化为不破坏既有调用契约、且后端新增工作量最小（仅 1 个聚合端点）的重构落地。

## 2. 功能描述

### 2.1 信息架构（6 区块 + 退出）
左侧状态栏顶部固定"身份卡"（头像 + 昵称 + 会员徽标 + mini 用量环），其下导航：`概览` / `我的车库` / `用量` / `账户` / `会员` / `订单`，底部为带二次确认的`退出登录`。默认首屏为`概览`。

### 2.2 各区块功能
- **概览（新增，默认首屏）**：Hero 动态文案（"欢迎回港，{昵称}"）；三枚遥测读数卡（会员徽标+到期日 / 配置额度环形% / 对话额度环形%）；"最近作品"取车库前 3 件并支持跳转；双 CTA（继续改装 / 管理会员）。
- **我的车库（新增，核心）**：复用 `GET /api/garage` 渲染用户生成作品网格（缩略图 4:3 + 车型 + 模式标签 + 相对时间）；空态插画 + 引导按钮；点击打开详情浮层（大图 + 元数据，复用现有 `pc-sub-popup` 结构）。
- **用量（新增/强化）**：配置/对话额度各一张仪表卡（线性进度条 + 剩余/总额 + 重置日期）；近 7 日消耗火花线（来自新增 `GET /api/usage`）；低于阈值（如 20%）转琥珀告警条。
- **账户（重组现有）**：拆为`资料`（昵称/邮箱各自独立保存，头像编辑并入）/ `绑定`（手机号 + 验证码换绑）/ `安全`（改密码入口 → 复用 `PasswordChangePopup`）三组卡片。
- **会员（去拥挤）**：顶部当前方案卡 + 三档定价对比卡（FREE/PRO 推荐/MAX）+ 支付浮层；按 `USER_SUBSCRIPTION_CHECKOUT_ENABLED` 双态呈现（自助 / 联系管理员）。
- **订单（卡片化）**：由 6 列裸表改为订单卡片列表（方案名/金额/支付方式/状态徽标/时间），状态色化。

### 2.3 非功能性需求
- 桌面端 light 主题跟随端上 `data-theme` 切换（补齐此前缺失的 PC light 变量）。
- 导航支持键盘（Tab/方向键/Home/End），焦点环清晰（`--teal-glow`），状态 `aria-live` 播报。
- 面板载入 staggered 编排动画，尊重 `prefers-reduced-motion`。
- 所有动效仅用 transform/opacity 合成属性，不触发 layout。

## 3. 技术实现思路

### 3.1 总体策略
- **仅重写 `components/pc-account-panel.tsx` 的内部结构与 `app/globals.css` 中对应类**；`PcAccountPanel` 的 props 契约（`open / language / authUser / billing / onClose / onAuth / onAccountUpdated / onBillingUpdated / onLogout`）保持不变，故 `car-mod-studio.tsx` 零改动。
- **复用现有数据层与子组件**，不重写逻辑：`lib/account-client`、`lib/subscription-display`、`lib/subscription-checkout`、`lib/use-subscription-plans`；子组件 `AccountAvatar`、`AvatarPickerPopup`、`PasswordChangePopup`、`PaymentPopup`。
- **新增 1 个接口** `GET /api/usage`（§4 接口变更）。其余接口全部复用：`GET /api/garage`、`GET /api/billing/orders`、`GET /api/billing/plans`、`GET /api/billing/status`、`POST /api/billing/checkout`。
- **无 Tailwind**：继续纯 CSS 变量 + 手写类（项目无该依赖，且 `StyledSelect` 等已依赖手写 CSS，混用会破坏构建）。

### 3.2 设计令牌落地（对应 UI优化方案.md §3.1）
在 `app/globals.css` `:root` 基础上补充 `--teal` / `--teal-dim` / `--teal-glow` / `--amber` / `--grid-line` / `--radius` / `--radius-sm` / `--hud-line`；新增 `.pc-account-panel[data-theme="light"]` 覆盖（浅纸底 + 降饱和青绿强调），值可借用移动端 `.mobile-studio-app` 的 light token，保证跨端一致。

### 3.3 字体落地
在 `app/layout.tsx` 通过 `next/font` 加载等宽字体（如 JetBrains Mono）替换当前"仅依赖系统字体"的 `--font-mono`，保证跨机一致；中文走系统 `PingFang SC / Microsoft YaHei`。**回退策略**：若构建环境无法联网拉取，`next/font` 回退到系统 mono（沿用现状），不阻塞发布。

### 3.4 区块实现逻辑（无代码，仅描述）
- **身份卡 + 导航**：状态栏顶部 `authUser.avatarUrl` + 昵称 + `planDisplayName(billing.plan)` 徽标；mini 用量环用 SVG `stroke-dasharray/offset` 表达 `configUsed/configRemaining` 比例。
- **概览**：异步拉取车库（面板打开时 `fetch('/api/garage')` 一次，缓存于 state）；读数卡复用 `formatAccountQuota`；Hero 文案与"本月已改装 N 台"由车库数组长度/时间推断。
- **我的车库**：网格映射 `GenerationJob[]`；详情浮层复用 `pc-sub-popup` 结构展示 `resultImageUrl` 与元数据。
- **用量**：仪表卡用 `billing` 快照；火花线由 `GET /api/usage?days=7` 的每日数组绘制 SVG `polyline`，hover 显示当日值（title/tooltip）。
- **账户/会员/订单**：沿用现有 `AccountSection` / `SubscribeSection` / `OrdersSection` 的逻辑，仅重构 JSX 结构与类名以匹配新卡片化布局，并补充 `htmlFor`/`id` 与 `aria-live`。
- **退出确认**：新增轻量确认浮层，确认后才调用 `onLogout()`。

### 3.5 动效与 a11y
- framer-motion 编排：backdrop fade → 面板位移/缩放 → 内容子块 `animation-delay` 阶梯揭示。
- 导航 `role="tablist"` + `aria-selected`，方向键切换；焦点环统一 `--teal-glow`；保存/换绑/低额度走 `aria-live="polite"` 播报。
- 尊重 `prefers-reduced-motion`：降级为纯淡入。

### 接口变更
| 接口路径 | 操作 | 说明 |
|----------|------|------|
| `GET /api/usage` | 新增 | 入参 `days`（默认 7，上限 30）；`requireUser()` 鉴权；返回 `[{ date, configUsed, chatUsed }]` 近 N 日序列（数据来自 `usage_ledger`/`entitlement_usage`）。支撑用量火花线。 |

## 7. 实施步骤

> 阶段划分，每步为原子动作；Phase 1 后端最小、可独立合并。

1. **Phase 1 — 后端（最小）**
   1. 在 `lib/server/db.ts` 新增 `getUsageSeries(userId, days)`，聚合 `usage_ledger`/`entitlement_usage` 近 N 日每日 `used`。
   2. 新增 `app/api/usage/route.ts`（`GET`，`requireUser()` + 调用 `getUsageSeries`），返回日期序列 JSON。
   3. 在 `lib/account-client.ts` 新增 `getUsageSeries()` 客户端封装。
   4. 验证端点：本地起服务，`curl` 验签与字段。

2. **Phase 2 — 设计令牌与基础骨架**
   5. `app/globals.css` 追加 §3.2 的 `--teal` 等 token，并补 `.pc-account-panel[data-theme="light"]` 覆盖。
   6. `app/layout.tsx` 接入 `next/font` 等宽字体并写入 `--font-mono`（含回退）。
   7. `pc-account-panel.tsx` 重构外层结构：状态栏（身份卡 + 6 导航 + 退出确认）+ 右栏内容容器 + backdrop/HUD 网格背景；props 契约保持不变。

3. **Phase 3 — 各区块落地**
   8. 新增 `OverviewSection`（Hero + 三读数卡 + 最近 3 作品 + CTA），面板打开时 fetch `/api/garage` 一次缓存。
   9. 新增 `GarageSection`（网格 + 空态 + 详情浮层），映射 `GenerationJob[]`。
   10. 新增 `UsageSection`（仪表卡 + 火花线取自 `/api/usage` + 低额度告警）。
   11. 重组 `AccountSection` 为资料/绑定/安全三组卡片，补充 `htmlFor`/`id`。
   12. `SubscribeSection`→`MembershipSection` 去拥挤，按开关双态呈现。
   13. `OrdersSection` 改为卡片列表 + 状态徽标。
   14. 退出确认浮层替代直接登出。
   15. 补充 `usePanelCopy` 中概览/车库/用量相关文案（中英双语）。

4. **Phase 4 — 动效与可访问性**
   16. 面板载入 staggered 编排（backdrop → 面板 → 子块 `animation-delay`）。
