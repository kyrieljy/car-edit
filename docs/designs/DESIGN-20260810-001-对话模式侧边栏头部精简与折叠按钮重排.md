# DESIGN-20260810-001：对话模式侧边栏头部精简与折叠按钮重排

## 元信息
- **创建日期**：2026-08-10
- **状态**：已实施
- **关联需求**：PC 桌面端对话模式侧边栏，去掉左上角 "* AI 助手" 整行，将右侧的折叠（缩进）按钮移到下方搜索框同一行，折叠/展开效果保持不变。

---

## 1. 背景

对话模式（`components/chat-mode.tsx` 的 `ChatHistorySidebar`）左侧历史侧边栏顶部有一行头部：
- 一个圆形星标徽章 `*`（`assistant-mark`）；
- 文字 "AI 助手"（`t.assistant`）；
- 其右侧一个折叠/展开切换按钮（`PanelLeftClose` / `PanelLeftOpen`，移动抽屉下为 `X`）。

产品希望在 **PC 桌面端** 精简这一行：移除整行（星标 + 文字），并把折叠按钮下移，与下方的搜索框同一行，使整体更紧凑；同时折叠（收成 88px 窄条）与展开（恢复 320px）的能力保持不变。

## 2. 功能描述

- **桌面展开态（320px）**：不再渲染头部行。搜索框所在行变为 `[折叠按钮] + [搜索胶囊]` 同一行；折叠按钮位于搜索框**左侧**。点击该按钮 → 侧边栏折叠为 88px 窄条。
- **桌面折叠态（88px）**：不再渲染头部行。沿用现有 `collapsed-actions`（"+" 新建按钮 + 放大镜搜索按钮）；点击搜索按钮 → 侧边栏展开回 320px。展开入口与现在一致。
- **移动端抽屉**：本次**不改变**。移动抽屉仍保留头部（星标 + "AI 助手" + `X` 关闭按钮）与现有行为；移动抽屉当前本就不渲染搜索框（代码里搜索框外层为 `{!isMobileDrawer && ...}`）。
- **效果不变**：桌面端的折叠/展开能力、动画、宽度（320 / 88）均保持现有表现；仅头部行被删除、折叠按钮位置改变。

## 3. 技术实现思路

仅涉及 `ChatHistorySidebar` 组件的结构重排与少量 CSS，不涉及数据、接口或状态机变更。

### 组件结构（逻辑描述，不生成代码）

1. **头部分支条件化**
   - 原 `.chat-history-head` 整块（星标 `*` + `<strong>AI 助手</strong>` + 切换按钮）改为**仅在移动抽屉态**（`isMobileDrawer === true`）渲染，桌面端不渲染。
   - 桌面端的 `effectiveCollapsed` 仍由 `collapsed` 控制（移动抽屉强制 `false`），因此桌面折叠/展开逻辑不受影响。

2. **折叠按钮下移到搜索行**
   - 在桌面展开态的 `.chat-sidebar-expanded` 内，将原来的头部切换按钮移动到搜索框上方那一行。
   - 新增一个 flex 行容器（如 `.chat-search-row`），按顺序包含：
     - 折叠按钮（桌面展开态固定显示 `PanelLeftClose`，点击 `handleSidebarToggle` 即 `setCollapsed(true)`）；
     - 现有 `<label className="chat-search">`（搜索图标 + 输入框），设为 `flex: 1` 占据剩余宽度。
   - 该按钮**仅桌面端**渲染（`!isMobileDrawer`），移动抽屉继续使用头部 `X` 关闭，不在此行出现。

3. **折叠态保持不变**
   - `.collapsed-actions`（"+" 与搜索按钮）维持原样；其搜索按钮的 `onClick={() => setCollapsed(false)}` 仍作为展开入口，无需新增按钮。

### CSS 调整（逻辑描述）

- 新增 `.chat-search-row`：`display:flex; align-items:center; gap`（复用现有间距语义）；承担原来 `.chat-search` 的外边距（`margin: 18px 14px 0` 之类），作为顶部留白与水平边距。
- 将 `.chat-search` 自身的 `margin` 改为 0，并加 `flex: 1`，使其在新行内自适应宽度；保持原有圆角胶囊外观与内边距。
- 折叠按钮样式复用/对齐现有 `.chat-history-head button`（34×34、圆角、hover 背景）即可，无需新造型。
- 桌面端不再使用 `.chat-history-head` 与 `.chat-history-head.collapsed`，但移动抽屉仍使用 `.chat-history-head`，因此这些 CSS **保留**；`.chat-history-head.collapsed` 等仅移动端用不到的规则可标记待清理（可选，低优先级）。
- 需人工核对两处媒体查询/活动态覆盖（约 `globals.css` 第 12029、12033、22786 行，均针对 `.chat-history-head`/`.chat-search`）：因移动抽屉仍保留头部，规则继续有效，桌面端不再依赖头部，无回归。

## 修订（2026-08-10 二次改动）

用户追加调整折叠态（88px）表现，推翻原"保留 collapsed-actions 搜索按钮展开"的决策：

- 移除 `collapsed-actions` 中的「新建对话」(`+`) 与「搜索」(放大镜) 两个按钮。

- 折叠态不再提供"新建对话"入口（需先展开再操作）；这与第 2、3 条确认项的最终取向一致。
