# DESIGN-20260727-002：PC 端浮动菜单折叠/展开功能

## 元信息
- **创建日期**：2026-07-27
- **状态**：已实施
- **关联需求**：将 PC 端菜单悬浮窗口紧贴窗口左侧，添加"<"折叠按钮隐藏菜单，仅保留">"展开按钮紧贴左侧，点击恢复菜单显示。

---

## 1. 背景

当前 PC 端浮动垂直菜单（`.app-floating-rail`）固定显示在窗口左侧（`left: 12px`），包含改图、生图、视频、特效 4 个按钮，无法收起。当用户专注于生成结果预览或对话交互时，菜单始终占据左侧视觉空间。需要提供折叠能力，让用户按需隐藏菜单以获得更大的内容可视区域，同时保留一键恢复入口。

## 2. 功能描述

### 核心用户故事
- 作为 PC 端用户，我希望能够将左侧浮动菜单折叠隐藏，以获得更大的内容可视区域。
- 作为 PC 端用户，我希望折叠后仍有一个紧贴左侧的展开按钮，方便随时恢复菜单。

### 功能行为
1. **菜单紧贴左侧**：浮动菜单的 `left` 偏移调整为更贴近窗口左边缘（由 `12px` 调整为 `4px`），视觉上"紧贴"窗口左侧。
2. **折叠按钮**：在 4 个菜单按钮（改图、生图、视频、特效）下方添加一个"<"样式按钮，使用 `ChevronLeft` 图标。
3. **折叠行为**：点击"<"按钮后，整个菜单容器（含 4 个菜单按钮和"<"按钮）隐藏，仅显示一个">"样式按钮（`ChevronRight` 图标）紧贴窗口左侧。
4. **展开行为**：点击">"按钮后，恢复完整菜单显示（4 个菜单按钮 + "<"按钮），">"按钮隐藏。
5. **状态记忆**：折叠/展开状态为会话级状态（`useState`），不持久化到 localStorage，页面刷新后恢复为默认展开状态。
6. **生效范围**：仅 PC 端（`min-width: 761px`），移动端不受影响。

### 非功能性需求
- 折叠/展开切换需有平滑过渡动画，与现有菜单 hover 过渡风格一致（`transition: 0.2s`）。
- 亮色/暗色主题下均需正常显示，沿用现有 CSS 变量（`--surface`、`--line-soft`、`--muted` 等）。

## 3. 技术实现思路

### 整体策略
在 `CarModStudio` 组件中新增一个 `menuCollapsed` 布尔状态，控制菜单的折叠/展开。通过条件渲染或 CSS 类名切换实现菜单容器与展开按钮的显隐。

### 状态管理
- 新增 `const [menuCollapsed, setMenuCollapsed] = useState(false)`，默认 `false`（展开）。

### DOM 结构调整
现有结构：
```
<nav className="app-floating-rail">
  <button>改图</button>
  <button>生图</button>
  <button>视频</button>
  <button>特效</button>
</nav>
```

调整为两个互斥的容器：
- **展开态**（`menuCollapsed === false`）：渲染 `.app-floating-rail` 容器，内含 4 个菜单按钮 + 1 个"<"折叠按钮（`.app-rail-item` 样式，位于按钮组末尾）。
- **折叠态**（`menuCollapsed === true`）：渲染 `.app-floating-rail-collapsed` 容器，内含 1 个">"展开按钮。

两个容器均使用 `position: fixed`，`top: 50%`，`transform: translateY(-50%)`，`left` 值一致（`4px`），确保视觉位置统一。通过条件渲染（`menuCollapsed ? <折叠态> : <展开态>`）保证同一时刻仅一个容器存在于 DOM 中。

### 图标选择
- 折叠按钮"<"：使用 `lucide-react` 的 `ChevronLeft`（需新增 import）。
- 展开按钮">"：使用 `lucide-react` 的 `ChevronRight`（需新增 import）。

### CSS 变更
- 修改 `.app-floating-rail` 的 `left` 由 `12px` 改为 `4px`。
- 新增 `.app-floating-rail-collapsed` 样式类，样式与 `.app-floating-rail` 基本一致（固定定位、居中、背景、边框、阴影），仅包含单个按钮。
- 折叠/展开按钮复用现有 `.app-rail-item` 样式，保证视觉一致性。
- 为折叠/展开容器添加 `transition` 以实现平滑出现/消失效果。

### 主题适配
所有新增样式均使用现有 CSS 变量（`--surface`、`--line-soft`、`--shadow`、`--muted`、`--accent`），无需额外主题处理。根据项目硬约束，若涉及亮色模式调整需限定在 `[data-theme="light"]` scope，但本方案仅复用已有变量，不引入新的硬编码颜色，因此无需额外亮色适配。

## 7. 实施步骤

1. 在 `components/car-mod-studio.tsx` 的 lucide-react import 块中新增 `ChevronLeft` 和 `ChevronRight`。
2. 在 `CarModStudio` 组件中（`activeMenu` 状态附近）新增 `menuCollapsed` 状态，默认 `false`。
3. 将现有的 `<nav className="app-floating-rail">` 区块（第 1629-1666 行）重构为条件渲染：当 `menuCollapsed === false` 时渲染完整菜单（4 个菜单按钮 + 追加 1 个"<"折叠按钮，点击调用 `setMenuCollapsed(true)`）；当 `menuCollapsed === true` 时渲染折叠态容器（1 个">"展开按钮，点击调用 `setMenuCollapsed(false)`）。
4. 在 `app/globals.css` 的 `.app-floating-rail` 规则中，将 `left: 12px` 修改为 `left: 4px`。
5. 在 `app/globals.css` 中新增 `.app-floating-rail-collapsed` 样式类，复用 `.app-floating-rail` 的定位与外观变量，并在 `@media (min-width: 761px)` 中设置 `display: flex`，默认 `display: none`。
6. 本地启动 `npm run dev`，验证 PC 端（宽屏）菜单折叠/展开交互正常，移动端不受影响，亮/暗双主题显示正常。
