## 1. 背景

当前移动端个人中心的三个编辑子页面（编辑资料、换绑手机号、修改密码）通过 `renderProfileEditorShell()` 渲染为全屏覆盖层。现有设计存在以下问题：

- **表单视觉臃肿**：`.mobile-profile-editor` 使用 24px 大圆角卡片边框 + 边框背景，输入框上方有 label 标签，整体信息密度低、视觉层次混乱
- **输入框风格陈旧**：输入框使用 16px 圆角 + 边框 + 半透明背景，缺乏现代感，无清除按钮等便捷交互
- **按钮风格不统一**：提交按钮使用 16px 圆角 + 渐变背景，与整体设计语言不够协调
- **缺乏页面引导**：子页面仅有标题，无副标题说明，用户进入后缺乏上下文引导

参考项目 `create-username-ui` 采用 iOS 原生风格设计：纯黑背景、深色输入卡片（#1c1c1e，14px 圆角）、药丸形按钮（rounded-full）、居中标题+副标题、输入框内含清除按钮、绿色验证反馈。本次重构将借鉴该布局与风格，同时保持项目现有的绿色/青色（#67ffca）强调色，仅适配暗色主题。

## 2. 功能描述

### 核心变更

将三个编辑子页面（编辑资料、换绑手机号、修改密码）的表单布局从「label + 边框卡片 + 圆角按钮」重构为「placeholder 深色输入卡片 + 药丸按钮 + 副标题引导」，视觉风格对齐 `create-username-ui`，颜色保持绿色/青色强调色。

### 具体功能点

1. **副标题引导**（新增）
   - 在 `renderProfileEditorShell` 的 topbar 标题下方新增副标题区域
   - 各子页面副标题：
     - 编辑资料：「个性化你的账号资料和头像」/「Personalize your profile and avatar」
     - 换绑手机号：「输入新手机号并完成验证」/「Enter a new phone number and verify」
     - 修改密码：「设置一个新的登录密码」/「Set a new login password」
   - 副标题样式：居中、`--m-muted` 颜色、14px 字号、1.5 行高

2. **输入框重构**
   - **移除所有 label 标签**，改用 `placeholder` 属性提示字段用途
   - 输入框改为深色卡片样式：
     - 背景：`--m-panel`（#111317）
     - 圆角：14px
     - 无显式边框（或极淡边框 `rgba(255,255,255,0.06)`）
     - 最小高度：50px
     - 内边距：0 16px
     - 字号：17px
   - 每个输入框右侧添加**清除按钮**（输入有值时显示）：
     - 18x18px 圆形按钮
     - 背景：`--m-muted` 半透明
     - 内含 X 图标（10x10px）
     - 点击清空对应输入框
   - 密码输入框同样添加清除按钮

3. **提交按钮重构**
   - 改为药丸形（border-radius: 9999px）
   - 背景：`--m-cyan`（#67ffca）
   - 文字颜色：#050607（黑色）
   - 字号：17px、字重 600
   - 最小高度：50px
   - 全宽
   - 点击缩放反馈：`active:scale-[0.98]`

4. **换绑手机号验证码行**
   - 验证码输入框 + 发送按钮在同一深色卡片内
   - 发送按钮改为文字链接风格（`--m-cyan` 颜色文字，无背景）
   - 中间用竖线分隔

5. **编辑资料 - 头像选择器**
   - 保留头像选择功能，样式精简
   - 移除 fieldset/legend 边框
   - 头像按钮改为：选中态使用 `--m-cyan` 边框 + 轻微绿色背景
   - 网格布局保持 4 列

6. **状态/错误反馈**
   - 简化为纯文字 + 图标（移除边框框和背景色）
   - 成功状态：`--m-cyan` 颜色文字 + 勾选图标
   - 错误状态：`#f87171` 颜色文字 + 警告图标
   - 字号：13px、字重 500

7. **表单容器**
   - 移除 `.mobile-profile-editor` 的卡片边框和背景
   - 改为纯间距容器（gap: 16px，无边框、无背景、无圆角）

### 非功能性需求

- **仅适配暗色主题**，不编写 `[data-mobile-theme="light"]` 变体
- 页面过渡动画（framer-motion）保持不变
- 状态管理、数据获取、API 调用逻辑保持不变
- overview 主页面和其他子页面（消息、订单、历史）不受影响

## 3. 技术实现思路

### 整体策略

仅修改 `MobileProfilePage` 组件中三个表单子页面（`section === "profile"` / `"password"` / `"phone"`）的 JSX 渲染结构，以及 `renderProfileEditorShell` 添加副标题支持。对应的 CSS 样式在 `app/globals.css` 中修改。不涉及状态管理、数据获取、API 调用等逻辑变更。

### JSX 结构变更

#### 3.1 `renderProfileEditorShell` 增加副标题

在 topbar 的 `<strong>` 标题下方新增副标题 `<p>` 元素，副标题文本根据 `section` 值确定：

```
header（topbar）
  ├── back button
  ├── strong（标题）
  └── p（副标题，新增）
section（body）
  ├── children（表单内容）
  └── status（状态反馈）
```

#### 3.2 输入框组件化

为减少重复代码，将输入框 + 清除按钮封装为内部辅助函数 `renderInput`：

```
function renderInput(value, onChange, placeholder, type?)
  → div.mobile-profile-input-wrap
      ├── input（placeholder 驱动，无 label）
      └── button.mobile-profile-clear-btn（value 非空时显示）
```

#### 3.3 编辑资料表单重构

从：
```
form.mobile-profile-editor
  ├── fieldset.mobile-avatar-picker（legend + grid）
  ├── label > span「昵称」 + input
  ├── label > span「邮箱」 + input
  └── button「保存资料」
```

重构为：
```
form.mobile-profile-editor
  ├── fieldset.mobile-avatar-picker（无 legend，直接 grid）
  ├── renderInput(name, placeholder「昵称」)
  ├── renderInput(email, placeholder「邮箱」)
  └── button「保存资料」（药丸形）
```

#### 3.4 修改密码表单重构

从：
```
form.mobile-profile-editor
  ├── label > span「当前密码」 + input[type=password]
  ├── label > span「新密码」 + input[type=password]
  ├── label > span「确认新密码」 + input[type=password]
  └── button「修改密码」
```

重构为：
```
form.mobile-profile-editor
  ├── renderInput(currentPassword, placeholder「当前密码」, type=password)
  ├── renderInput(nextPassword, placeholder「新密码」, type=password)
  ├── renderInput(confirmPassword, placeholder「确认新密码」, type=password)
  └── button「修改密码」（药丸形）
```

#### 3.5 换绑手机号表单重构

从：
```
form.mobile-profile-editor
  ├── label > span「新手机号」 + input
  ├── label > span「验证码」 + div.mobile-profile-code-row > input + button「发送」
  └── button「确认换绑」
```

重构为：
```
form.mobile-profile-editor
  ├── renderInput(phone, placeholder「新手机号」)
  ├── div.mobile-profile-input-wrap（验证码行）
  │   ├── input（placeholder「验证码」）
  │   ├── button.mobile-profile-clear-btn（清除按钮）
  │   └── button.mobile-profile-code-send（文字链接风格「发送验证码」）
  └── button「确认换绑」（药丸形）
```

### CSS 变更策略

5. **新增 `.mobile-profile-clear-btn`**：

6. **修改 `.mobile-profile-editor > button`（提交按钮）**：
   - `border-radius: 9999px`（药丸形）
   - `background: var(--m-cyan)`（#67ffca）
   - `color: #050607`（黑色文字）

   - `min-height: 50px`
   - `border: none`
   - `active:scale(0.98)` 缩放反馈

7. **修改 `.mobile-profile-code-row`**：
   - 改为 `.mobile-profile-input-wrap` 内的布局
   - 发送按钮改为文字链接风格

   - `color: var(--m-cyan)`

9. **修改 `.mobile-profile-status`**：
   - 移除 `border`、`background`

   - `color: var(--m-cyan)`（成功）

   - 添加图标（Check/AlertCircle）

10. **修改 `.mobile-profile-status.error`**：
    - `color: #f87171`
    - 同样无边框、无背景

11. **修改 `.mobile-avatar-picker`**：
    - 移除 legend 显示（`display: none` 或不渲染）

### 交互逻辑

- 所有表单提交逻辑（`saveProfile`、`savePassword`、`savePhone`、`sendCode`）保持不变
