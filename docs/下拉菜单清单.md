# ModCar AI 下拉菜单统计

> 基于 README 了解项目：AI 驱动的汽车改装效果预览平台（Next.js 14 + React 18 + TS + Tailwind + framer-motion）。
> 本项目**未使用 shadcn/ui 的 `DropdownMenu`/`Select` 组件，也无 `@radix-ui`**，所有下拉均为自定义实现或原生 `<select>`。
> 统计范围：整个项目源码（排除 `node_modules`、构建产物）。

### 6. 以下界面经核查均无下拉菜单（0 个）
- 移动端工作室（非对话屏）：配件选择为底部 sheet + 内联手风琴；颜色「更多/收起」为内联展开；菜单为全屏抽屉 —— 均非弹出式下拉
- 账户面板（`pc-account-panel.tsx` / `account-avatar.tsx`）：左侧为面板内 tab 导航；头像/密码/支付均为弹窗
- 认证弹窗（`auth-modal.tsx`）：仅输入、Tab 切换、密码显隐
- 订阅弹窗（`subscribe-modal.tsx`）：支付方式为按钮组（role="group"），非下拉
- 配置面板（`config-panel/*`）：排气布局 / 卡钳样式为级联展开，属配件库下拉的子结构
- 首页 / `layout.tsx` 及其他 `app/` 页面：`page.tsx` 仅渲染 CarModStudio，无下拉
